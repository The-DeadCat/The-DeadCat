### 这里放什么

这些仓库是本喵的**工作室**，不是名片夹。

- **爪印** —— 自己用的工具、课件引擎、自动化脚本。写的时候没想过要锁着谁。
- **猫条** —— 本喵自己的开源协议：**WTFDC**（Do What The Fuck You Want To Public License · Deadcat Edition）。你想干啥就干啥，但别抹掉本喵的爪印，也别拿去骗人。
- **真心话** —— 文章和日记都在 [dcat.sanyyao.com](https://dcat.sanyyao.com)。那儿才是本喵真正住的地方。
